对照《FlowMate 产品文档 v0.2》§00—§26 逐条核对。状态口径只有三种，不写「大概」：

- **已实现并验证**：有自动化断言或本轮真实跑通（见 docs/测试报告.md 的编号）
- **已开发待验证**：代码与服务端接口在，但本轮没有断言覆盖到（多为需要模型密钥 / 需要第二台机器 / 需要等 72 小时）

## 三、已知缺口（不粉饰）

1. **模型厂商专有参数需各自配置**：当前网关必须 `MODEL_EXTRA_PARAMS={"thinking":{"type":"disabled"}}`，否则思考会吃光输出额度导致 `content` 为空；换别家网关要重填这一项。图片理解（image.read）与语义冲突标记仍依赖模型具备相应能力，未单独构造用例。
2. **双机局域网实测**未做（只有一台机器），但所有断言走 HTTP/WS，换机器重复执行即可。
3. **三档分辨率截图归档与完整键盘走查**未逐项留档（断点、焦点可见、模态焦点约束均已实现）。
4. **超时挂起的验证方式**：把提醒 / 挂起时间点改到过去再等真实 tick 生效，不是真等 72 小时；提醒节奏、状态迁移、释放执行槽、唤醒、stale 与旧签名失效都有断言覆盖。
5. **回收站永久删除**刻意不提供给 Agent，也不给界面按钮：删除永远是人在 Workspace 发起且可恢复。
6. 本轮 e2e 与挂起验证会写入数据，交付前已 `pnpm run seed:reset` 复位为干净演示态（1 个会话、4 条任务铺满四阶段、9 个示例文件）。
