## 规格统一做了什么

原图约 1250×1250 ~ 1252×1254（非正方形、每张 2.1–2.5 MB）。处理方式：**以画面中心裁出正方形** → **面积平均缩放到 512×512** → 重新编码为 RGBA PNG（保留 sRGB 与 pHYs 标记，**不携带任何来源元数据**）。

合计体积 13.41 MiB → **2.74 MiB**；`dist/client` 里的副本同样从 13.41 MiB 降到约 2.7 MiB，交付包总重量随之下降约 21 MiB。

已核验：色彩无异常、无缩放伪影、人物严格居中、头顶与两侧发型完整、背景纯净、Alpha 通道正常，缩到 34–48px 仍可辨识。
